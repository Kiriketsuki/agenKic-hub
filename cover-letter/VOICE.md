# Jovian's voice — cover letter card

Distilled from `710-Voice-and-Persona/` references and the OGP letter. Read this before drafting; check the draft against it after.

## The register

Warm, direct, a little playful, never corporate. Sounds like a capable engineer talking to another engineer over coffee, not a candidate performing for HR. Sentences chain with commas and "and"; some run a little long, and that is fine. Fragments are not the style; full sentences are.

## Signature moves (use these)

| Move | Example from the references |
|---|---|
| Validation before correction | "Fastify is a good choice, but Express is the standard" |
| Utility-grounded philosophy | "Diagrams are just there to help the humans understand the shape of the system" |
| Self-aware aside | "I can't help but start to do some engineering analysis of my own" / "can't help myself" |
| Plain enthusiasm | "I like that the team isn't done building. I want to be a part of that" |
| Honest capability framing | "My default frontend is Vue, not React, but ... the mental model is the same, and I pick things up fast" |
| Concrete stakes | "the cost is delayed flights and someone's luggage not making it" |
| Personal connection to the product | "whenever I want to set up a fun and active date night with my girlfriend" |
| Owning mistakes plainly | "our bug — but MySQL failed silently under it" |

## Banned (these are the tells of AI-polished writing)

- Em-dashes. Use commas, full stops, or parentheses.
- Aphorisms and chiasmus ("X is work, but Y is education"; "not just X, but Y").
- Triadic rhetorical symmetry ("real-time constraints, unforgiving schedules, and users who...").
- Consultant nouns: leverage, utilize, robust, spearheaded, passionate, delve, landscape, journey.
- "reads like", "sounds familiar rather than daunting", "the environment I have been working in, and the one I want to keep working in" (mirror constructions).
- Emojis. Flowery closers ("Warmest regards"). "I hope this finds you well."
- Inflated claims. If the experience is thin, say so and frame the transfer honestly.

## Fixed elements

- Opener: "I am applying for [role] on/at [team/company]." then the "I love building things" line, adapted, not copied verbatim every time.
- Pivot: "The resume covers my work history, and I would love to talk more about it anytime. Nonetheless, let me talk about why [this role/this team] in particular."
- Closer: "Happy to talk anytime, and thank you for reading." then "Best Regards, / Jovian".
- Product name: **Auto-Connect**. Email: **limzh.jovian@gmail.com**. Sign as **Jovian**.

## Self-check before showing the user

Read the draft aloud mentally. For each paragraph ask: would Jovian text this to a peer? If a sentence sounds like it belongs in a LinkedIn post or a McKinsey deck, rewrite it plainer. At least one line should carry a small smile (a self-aware aside or a dry observation), and no line should carry a bow tie.
