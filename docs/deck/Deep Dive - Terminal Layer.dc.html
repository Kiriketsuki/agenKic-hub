04 · Emulator

The emulator is not the shell.

Draws text, passes keys. Not the shell.
GPU-rendered and native. Smooth under heavy output.
No config file is created. Empty is valid.
No Windows build yet. WezTerm or Windows Terminal there.
# macOS
brew install --cask ghostty

# Windows stand-in
winget install wez.wezterm

mkdir -p ~/.config/ghostty
touch ~/.config/ghostty/config
Keep it in your dotfiles. Reload in place.

05 · Config

Five keys carry most of it.

font-family       = "JetBrainsMono Nerd Font"
font-size         = 13
theme             = catppuccin-mocha
background-opacity = 0.96
keybind = cmd+shift+enter=new_split:right
font-family must match exactly. A missing space falls back silently.
font-size goes up for screen sharing. Raise it before a demo.
keybind takes one binding per line.
Key equals value. No JSON, no settings panel.

+ Font Awesome · Devicons · Powerline

one font file
Same metrics. A drop-in replacement, not a new face.

08 · tmux

Server, session, window, pane.

Windows are tabs. Panes are a grid.
Prefix first: tap, release, press. Do not hold it.
Name your sessions. tmux ls is useful only when the names mean something.
tmux new -s work
tmux ls
tmux kill-session -t work

Ctrl-a c   # new window
Ctrl-a n   # next window
Ctrl-a %   # split vertical
Ctrl-a "   # split horizontal

09 · The payoff

Detach is not close.

Without tmux
SSH drops → shell exits → agent dies. Three hours gone.
With tmux
Runs on the server. Reattach anywhere, same panes.
Ctrl-a d                 # detach, session keeps running
tmux attach -t claude    # from any terminal, any machine

10 · Config

A small .tmux.conf.

# ~/.tmux.conf
unbind C-b
set -g prefix C-a
bind C-a send-prefix

set -g mouse on
setw -g mode-keys vi

bind r source-file ~/.tmux.conf \; \
  display "Config reloaded"
Ctrl-a sits closer to the home row. That is the whole reason.
mouse on lets a new user click a pane instead of memorising prefix-o.
tmux-resurrect and -continuum persist across a reboot.
Add an option when you miss it, not before.

13 · Honest limits

When the stock terminal is right.
