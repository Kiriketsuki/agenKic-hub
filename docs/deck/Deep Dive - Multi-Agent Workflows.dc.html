02 · The rule

A script coordinates. Agents act.

A workflow is a .mjs script that sequences three calls: agent(), parallel(), workflow().
Every world-touching action lives in an agent prompt.
Agents return schemas. The next stage reads structure, not prose.
A smoke script syntax-checks every one.
const plan = await agent(planPrompt, {
  schema: PLAN, model: 'top' })

const built = await parallel(
  plan.leaves.map(l => () =>
    agent(build(l), {schema: DIFF,
                    model: 'mid'})))

await workflow('council-loop', {branch})

04 · Council

Four roles debate a motion.

ADVOCATE
Argues for the motion. Never drifts to early consensus.
CRITIC
Argues against. Softens only with a cited reason.
QUESTIONER
Fires "why?" at any claim that skipped its reasoning. Never blocking.
ARBITER
Records concessions. Issues FOR, AGAINST or CONDITIONAL, cited.
Code motions: every agent reads the files first.

05 · Axiom

Real spawned agents, or nothing.

Role-played prose
One model writes both headers, agrees with itself, reports consensus.
It reads like a debate. It found nothing.
Separate contexts
Separate context, separate reading. Disagreement survives.
This costs more tokens. That cost is the product.

06 · Protocol

Every message follows three rules.

01  Exactly one header, the agent's role name.
02  Address the previous turn first.
03  Stay in the round's scope. A rebuttal is not a new argument.
A conceded point cannot be re-argued.
## CRITIC
@ADVOCATE: "The cache layer adds
no latency"
Counter: profiler output at
cache.ts:142 shows 12ms overhead

08 · Scope

Two tests, then a high bar.

The finding is directly about the motion.
The concern does not pre-date the motion.
Fail either and it is dropped. No wishlists.
SECURITYOWASP Top 10 or equivalent
DATA LOSScorruption, silent deletion, no rollback
COMPLIANCEa legal or regulatory blocker
Not performance, quality, style, debt or ideas. A critical find is a note.

09 · Supervision

Long debates need a supervisor.

adversarial-council
+ council-supervisor
council-fix
prioritised fix plan
Heartbeats and stall detection. One dead agent cannot hang a round.
Checkpoints between rounds. Replacement on no response.
Structured results out. No transcript parsing downstream.
Then: parallel-fix
Findings fan out to isolated worktrees, one strategy each.
Smallest passing diff wins. Losers are removed, not merged.

10 · spec-loop

A spec becomes a DAG.

wave 1schema · config · types
wave 2repository · service · adapters
wave 3handlers · UI · integration tests
Unblocked leaves run together. The next wave waits on its inputs.
Routed first: agent type, model tier, worktree.
Every PR faces a council. Unconditional FOR, not a green suite.
feature-loop trades breadth for depth: one feature, end to end.

11 · Cost

Assign a tier per role.

33
agents all inherited the top model. 2M tokens later, the session died.
Spend concentrates in fan-out. The top model does not belong there.
Thinker · design, hard root-causingTOP
Orchestrator · plans, arbitersTOP / MID
Implementer · appliers, portersMID
Reviewer · lenses, verificationDEPENDS
Escalate for a root cause that survived mid tier. Never for N lenses.

12 · autofix-swarm

Competing fixes need a gate.

diagnose
fan out competing worktree fixes
gate against gaming
promote a champion
council
An agent optimising for green weakens the assertion. It passes.
The gate reads the diff against its test before promotion.
The champion still faces a council.
Gaming, in practice
Delete the assertion. Widen the tolerance. Swallow the exception.
All four: green run, broken product.

13 · Portable

Steal these without the scripts.

Ask for the citation
"Which file and line?" Kills most confident guesses.
Run the critic separately
A second session that only argues against it.
Name the tier out loud

Check the test, not the run
Read what the assertion became, not that it passed.
