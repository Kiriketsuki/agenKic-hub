07 · Layer 03

The multiplexer.

Sessions hold windows. The session lives on the server.
The connection drops, the session does not.
The cost is one prefix key. That is it.

# Ctrl-a d, close the laptop

ssh devbox
tmux attach -t claude   ← still running

15 · Layer 10

Hooks: enforcement outside the model.

A shell command at a lifecycle point. Cannot be skipped.
Exit 0 proceeds. Exit 2 blocks and hands stderr back.
Check it in, and the gate travels with the repo.
PreToolUse · PostToolUse · SessionStart · Stop
# .claude/hooks/check-branch.sh
branch=$(git branch --show-current)
if [[ ! "$branch" =~ ^(feat|fix|chore)/ ]]; then
  echo "bad branch: $branch" >&2
  exit 2   # blocked before git runs
fi

17 · Layer 12

The adversarial council.

ADVOCATE
Argues the motion, cited.
CRITIC
Argues against. Never softens without a reason.
QUESTIONER
Fires "why?" at uncited claims, in parallel.
ARBITER
Returns FOR, AGAINST or CONDITIONAL. Records concessions.
## CRITIC
@ADVOCATE: "The cache layer adds no latency"
Counter: profiler output at cache.ts:142
shows 12ms overhead under load.
Real spawned agents. One model just agrees with itself.
Code claims cite file and line. Concessions are permanent.

CI: the agent without me.

Six files here: docs, release, three gates, issue-branch.
Tag @claude and it runs on a runner, not my laptop.
Credentials in repo secrets, never in the YAML.

  issue_comment:
    types: [created]
jobs:
  claude:
    if: contains(github.event.comment.body,
        '@claude')
    permissions: {contents: write,
      pull-requests: write, issues: write}
